Actualiser les questions DEV

Prépare tes questions dans la table Airtable, puis publie-les ici.

  1. Ajoute ou modifie une question avec Phase = Audio DEV et son texte dans Texte.
  2. Pour une question écrite, laisse Fichier audio vide. Pour une question à écouter, dépose ton enregistrement. Renseigne Prompt d’évaluation pour chaque réponse vocale.
  3. Passe État éditorial à Validée, puis clique sur Actualiser depuis Airtable. Les brouillons audio restent dans Airtable.
Ajouter un texte avec trois réponses vocales
  1. Utilise les trois lignes dev-mon-texte-01-q1, q2 et q3, déjà préparées en brouillon dans Airtable.
  2. Colle le texte à lire dans Texte support sur la première ligne. Écris une question par ligne dans Texte.
  3. Garde Groupe support = mon-texte-01 sur les trois lignes et Position dans le bloc = 1, 2, 3.
  4. Choisis Type = audio_response et Phase = Audio DEV. Renseigne un Prompt d’évaluation par question ; laisse le fichier audio vide.
  5. Pour essayer tes questions, garde le statut Brouillon et ouvre Tester mes questions ci-dessous. Pour les inclure dans l’application DEV, passe les trois lignes à Validée, puis actualise ici.
