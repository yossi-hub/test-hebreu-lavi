Fichier de démonstration : `question-demo.wav`, voix synthétique temporaire en hébreu (« מה עשית אתמול בערב? »).

Remplacez-le par votre propre enregistrement, en conservant son nom. Pour utiliser un MP3/M4A pour la question, placez-le ici et modifiez `audioDemo.media.url` dans `lib/audio-dev.js` ; ajoutez son extension dans le serveur local si nécessaire. Le fichier de **question** peut être MP3/M4A/WAV ; les **réponses** du navigateur sont toujours converties en WAV mono.

Ces fichiers sont publics une fois le site servi. Ne mettez aucune clé ni réponse vocale d’élève dans ce dossier.
